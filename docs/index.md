# DevOps Operations Handbook

Учебная документация: MkDocs, Pylint, GitHub Actions и GitHub Pages.

## Контур поставки

1. Изменения оформляются через Pull Request.
2. Pylint проверяет Python-код, MkDocs собирает сайт в строгом режиме.
3. После слияния в main отдельный workflow публикует проверенный сайт.

Читайте [руководство эксплуатации](runbook.md) и [журнал инцидентов](incidents.md).
