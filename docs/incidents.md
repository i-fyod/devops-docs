# Журнал инцидентов

## Статический анализ

Неиспользуемая локальная переменная вызывает Pylint W0612. Удаление переменной восстанавливает проверку.

## Ссылка на отсутствующую страницу

`mkdocs build --strict` завершает работу с ошибкой при предупреждении о несуществующей относительной ссылке. Исправьте путь или создайте целевую страницу.
